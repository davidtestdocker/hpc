# Benchmark Command

```bash
fio \
  --name=storage-test \
  --filename=/tmp/fio-test-file \
  --size=1G \
  --rw=readwrite \
  --bs=4k \
  --direct=1 \
  --runtime=60 \
  --time_based \
  --group_reporting
```

# Observation

- fio 成功建立 1GB Storage Workload。
- 使用 4KB Mixed Read/Write Pattern。
- Direct IO 避免 Page Cache 干擾。
- 本次測試目標為 Container Filesystem，而非 PostgreSQL PVC。
- 4KB Block Size 主要觀察 IOPS 與 Latency，而非最大 Sequential Throughput。
- 本次平均 Read/Write Latency 約 0.44 ms。
- Read / Write IOPS 約 1120。
- Read / Write Throughput 約 4.5 MiB/s。
