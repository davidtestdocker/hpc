## 先備知識與本課目標

先讀本週 README 的基礎解說，再依上方順序進入本課。目標是理解「CPU benchmark 子章」，並能把概念對到實際檔案；第一次不要求先懂完整平台架構。

## 概念解說

CPU 壓力工具可驗證負載生成與系統反應，但工具的 synthetic score 不等於業務效能。threads 與實際可用 CPU 配額不一致時，結果可能反映節流。

## 在現在的專案中

Day7 的子章按 7-1 到 7-7 閱讀，最後讀 day7-benchmark-report；不新增負載或覆寫舊結果。

本課對照：[benchmark/cpu/run_stress_ng.sh](<../../benchmark/cpu/run_stress_ng.sh>)。先看下面片段在檔案中的位置，再回到完整內容追輸入、處理與輸出。片段刻意只擷取相關起點，不可單獨貼去執行或 apply。

```bash
stress-ng \
  --cpu ${CPU_WORKERS} \
  --timeout ${TIMEOUT}s \
  --metrics-brief
```
